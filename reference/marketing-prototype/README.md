# Original SaltBox Marketing Prototype

Imported on 2026-08-25 from the repository-root `index.html`.

This directory contains the original SaltBox marketing prototype created before the production application architecture. The prototype is preserved as the approved visual, content, responsive-behavior, animation, and interaction reference for the future public SaltBox website.

The preserved `index.html` is a historical reference artifact. It should not become the production implementation, and it should not be modified as part of normal application development. Future developers and coding agents should preserve its approved design language unless a visual or product change is intentionally reviewed and approved.

The eventual production implementation will live under `apps/website`. It may use substantially different implementation details, but modernization does not authorize a redesign or disposal of this reference.

At import, the source prototype was self-contained: its HTML, CSS, JavaScript, SVG iconography, responsive behavior, and interactions were all embedded in `index.html`. It used externally hosted Google Fonts and contained no local asset references that needed to be copied with it.
