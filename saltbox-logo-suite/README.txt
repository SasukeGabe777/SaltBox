SALTBOX LOGO SUITE

Primary logo
- Use saltbox-logo-primary on dark backgrounds.
- Use saltbox-logo-dark on light backgrounds.

One-color logos
- Use the white or black versions when gradients are unavailable, for engraving,
  one-color printing, vinyl, stamps, or monochrome documents.

Logo mark
- Use saltbox-mark when the full name will not fit.
- Use saltbox-favicon for browser icons and square profile images.

Brand colors
- Ink: #0B0F0D
- Salt: #F2EEE4
- Green: #2AE08A
- Green 2: #16B86C

Typeface
- Bricolage Grotesque Bold (700)

File types
- SVG files stay sharp at any size and are best for websites, signs, and print.
- PNG files have transparent backgrounds unless the filename says favicon.
